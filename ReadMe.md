# iris-rolls
A module for foundry VTT and 5e that fixes a lot of the issues involved with selecting and targeting.

This first version is for test only so my friend can use it on ForgeVTT, but soon it will be considered Alpha. I will modify the readme then.

When you roll from a sheet, the sheet is the roller, and the targets are whoever you selected.

If you forgot to select someone, you can change the selected tokens on the chat card.

If you forgot to include advantage/disadvantage, you can change it on the chat card.

If you are casting an area effect spell, you will get a template that when you place it it will select targets automatically.

You can always override the selection manually from the chat card.

Saves are done automatically (including using evasion) <- maybe needs some work here for advantage/disadvantage and all the D&D5e rules.
You apply damage or effects by pressing Add Damage or Add Effects.

There is also a description button and an undo button on the chat card.
